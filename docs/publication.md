# Publication scope

Included: original Python research code and offline tests, rewritten technical documentation, a small curated synthetic-GUI summary, source hashes and ordinary build/CI metadata.

Excluded: original vendor EXE/DLL/SYS/CHM files, installers, full disassemblies, machine-specific configuration and calibration, license/registration data, original archives, raw captures/screenshots, local host configuration, private chat transcripts and local operating context. The public history starts from the selected snapshot rather than importing the private source repository's history.

The proprietary application was used as an analysis subject, not as vendored source. The summary includes formats, preferred-image addresses and a file hash to identify findings. It contains no executable patch or license bypass. No vendor code is relicensed by this repository.

The MIT License applies to the project's own code and documentation. Its permissive terms support protocol interoperability and research reuse. External documents and software retain their own terms. Linking to a manual does not grant redistribution rights to it.

Private original evidence remains necessary for a complete historical audit. The public summary makes that limitation explicit and does not present synthetic replies as physical-machine observations.
